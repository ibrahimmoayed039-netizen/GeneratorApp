# مدير المولدات (GeneratorApp)

تطبيق أندرويد لإدارة مبيعات المولدات، المشتركين، الأمبيرات، والفواتير، مبني بـ:
- **Kotlin** + **Jetpack Compose** (Material 3)
- **Room** لتخزين البيانات محليًا (تبقى محفوظة بعد إغلاق التطبيق)
- **طباعة مزدوجة**: حرارية ESC/POS (58مم/80مم) عبر البلوتوث + طباعة عادية عبر نظام أندرويد
- **معاينة الوصل** قبل الطباعة الفعلية بنفس الشكل تمامًا

## 📂 هيكل المشروع
```
app/src/main/java/com/example/generatorapp/
 ├─ data/            → Room: Entities + DAO + Database
 ├─ repository/      → طبقة وسيطة بين البيانات والواجهة
 ├─ viewmodel/        → MainViewModel
 ├─ printing/          → ReceiptData + EscPosPrinter + SystemPrintAdapter + PrintManager
 └─ ui/
     ├─ screens/       → الشاشات (الرئيسية، المشتركون، المولدات، الفواتير)
     ├─ components/    → ReceiptPreview (معاينة الوصل)
     ├─ navigation/    → التنقل بين الشاشات
     └─ theme/         → الألوان والخطوط (Material 3)
```

## ▶️ فتح المشروع في Android Studio
1. فك الضغط عن ملف ZIP.
2. افتح **Android Studio** → `Open` → اختر مجلد `GeneratorApp`.
3. عند أول فتح، Android Studio سيطلب توليد **Gradle Wrapper** تلقائيًا (لأن ملف `gradlew` الثنائي غير مرفق لتفادي حجم الملف) — وافق على ذلك أو نفّذ:
   ```bash
   gradle wrapper --gradle-version 8.7
   ```
4. انتظر Gradle Sync، ثم اضغط **Run** لتشغيل التطبيق على المحاكي أو جهاز حقيقي.

## 🖼️ شعار المحل
- من الشاشة الرئيسية → **"إعدادات المحل (الشعار)"** تقدر ترفع صورة الشعار (تُحفظ داخل `LogoManager` في تخزين التطبيق الخاص، وتبقى دائمة حتى بعد إغلاق التطبيق).
- الشعار يظهر تلقائيًا أعلى كل وصل في:
  - المعاينة على الشاشة (`ReceiptPreview.kt`)
  - الطباعة العادية عبر النظام (يُرسم داخل ملف PDF في `SystemPrintAdapter.kt`)
  - الطباعة الحرارية عبر البلوتوث (يُحوَّل لصورة نقطية أحادية اللون ويُرسل بأمر `GS v 0` في `EscPosPrinter.kt`)
- يستخدم منتقي الصور الحديث (Photo Picker) فلا يحتاج أي صلاحية وصول للمعرض.

## 💰 الميزات المالية الجديدة
- **كشف حساب شهري تلقائي**: من "كشف حساب شهري" اختر مشترك + شهر/سنة، ويظهر كل فواتيره خلال الفترة مع الإجمالي، وتقدر تطبعه.
- **تنبيه المتأخرين بالدفع**: شاشة "المتأخرون بالدفع" تعرض كل مشترك بدون فاتورة مسجّلة هذا الشهر. تقدر أيضًا تفعّل **تنبيه يومي تلقائي** (إشعار نظام) من شاشة الإعدادات يعمل حتى لو التطبيق مغلق (عبر WorkManager).
- **تقرير الأرباح**: شاشة "تقرير الأرباح" تعرض إجمالي الإيرادات وإجمالي المصروفات وصافي الربح، بالتبديل بين وضع شهري وسنوي.
- **المصروفات**: شاشة "المصروفات" لتسجيل مصاريف الديزل والصيانة وأي مصروف آخر، وتُستخدم تلقائيًا في حساب صافي الربح.

⚠️ **ملاحظة مهمة**: بما إن هذه الميزات تعتمد على ربط الفواتير بمعرّف مشترك حقيقي، صار لازم اختيار المشترك والمولد من **قائمة منسدلة** في شاشة الفواتير (بدل الكتابة الحرة)، وصارت كل فاتورة تُحفظ فعليًا في قاعدة البيانات فور إنشائها.

## 🖨️ الطباعة


- **حرارية (58مم/80مم)**: اقترن (Pair) بالطابعة عبر إعدادات البلوتوث بالجهاز أولاً، ثم اختر عرض الورق من شاشة الفواتير واضغط "طباعة حرارية".
- **عادية**: تضغط "طباعة عادية" ليظهر مربع حوار الطباعة القياسي في أندرويد وتختار أي طابعة مسجّلة (شبكة/USB/سحابية).
- **المعاينة**: تظهر تلقائيًا بنفس شكل الوصل قبل اختيار أي من طريقتي الطباعة.

## 📝 ملاحظات مهمة
- **APK التجريبي (Debug)** جاهز من GitHub Actions مباشرة بدون توقيع.
- لإصدار **APK نهائي موقّع (Release)** لنشره: تحتاج ملف Keystore + إضافة خطوة توقيع في الـ workflow (أخبرني إذا تحتاجها وسأجهزها لك).
- صلاحيات البلوتوث (`BLUETOOTH_CONNECT`, `BLUETOOTH_SCAN`) يجب طلبها وقت التشغيل (Runtime Permissions) على أندرويد 12+ قبل استخدام ميزة الطباعة الحرارية.
- قاعدة البيانات (`generator_app.db`) تُنشأ تلقائيًا داخل تخزين التطبيق الخاص، وتبقى محفوظة حتى بعد إغلاق التطبيق أو إعادة تشغيل الجهاز.

## 🔧 تطوير مستقبلي مقترح
- شاشة لعرض قائمة أجهزة البلوتوث المقترنة واختيار الطابعة يدويًا.

- شعار/لوقو مخصص للمحل يظهر أعلى الوصل.
